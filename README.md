# LaundryFlow 🧺

**LaundryFlow** adalah aplikasi web manajemen laundry modern, cepat, dan responsif yang dibangun menggunakan Vanilla HTML, CSS, dan JavaScript tanpa framework atau dependensi eksternal. Semua data disimpan secara lokal menggunakan `localStorage` browser.

---

## ✨ Fitur Utama

- **📊 Dashboard Interaktif**: Ringkasan omset harian/bulanan, total cucian aktif, pesanan selesai, dan grafik status.
- **📋 Manajemen Pesanan (Orders)**: Buat pesanan baru, hitung berat/satuan, pilih layanan cuci/setrika/express, dan tracking status cucian secara real-time.
- **💳 Transaksi & Pembayaran**: Pencatatan status lunas/belum lunas, metode pembayaran (Tunai, QRIS, Transfer Bank), dan cetak nota/struk digital.
- **⚙️ Pengaturan Layanan & Profil**: Kustomisasi daftar layanan laundry, tarif per kg/satuan, dan data outlet.
- **🌙 Dark Mode & Light Mode**: Desain antarmuka bersih (*Modern Utility Dashboard*) dengan transisi tema yang halus.
- **📱 Responsif**: Optimal untuk penggunaan di laptop, tablet, maupun smartphone.
